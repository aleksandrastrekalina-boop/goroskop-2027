# Параметры start для бота

Формат: `<знак>_<цель>_<приоритет>_<стиль>_ld`

- Знак: aries, taurus, gemini, cancer, leo, virgo, libra, scorpio, sagittarius, capricorn, aquarius, pisces
- Цель: money, home, real, life, change
- Приоритет: income, source, asset, project, stable
- Стиль решений: fast, calc, look, ask, late
- `ld` — метка источника (лендинг)
